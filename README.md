# Алёна Михайлова — сайт колориста

Сайт-визитка для колориста из Челябинска на React + Vite + Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`

## Сборка

```bash
npm run build
npm run preview
```

## Стек

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- [React Bits](https://reactbits.dev/) — анимированные компоненты (BlurText, Aurora, FadeContent, SpotlightCard)
- GSAP + Motion для анимаций

## Разделы сайта

- **Hero** — главный экран с анимацией Aurora
- **Обо мне** — информация об Алёне Михайловой
- **Услуги** — окрашивание, обучение, консультации
- **Обучение** — программа обучения колористике с нуля
- **Контакты** — адрес, режим работы, ссылка на VK
